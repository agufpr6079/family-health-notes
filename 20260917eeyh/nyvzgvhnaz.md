# 过年怎么吃才健康？

> 更新时间：2026-09-17 (UTC+8)

春节是中华民族的传统佳节，它是拜神祭祖、祈福辟邪、亲朋团圆、欢庆娱乐和聚餐饮食为一体的民俗大节。

   节日期间，与亲人、朋友欢聚一堂，往往少不了“觥筹交错”、“推杯换盏”，很容易暴饮暴食。

春节期间很多人容易**吃得多但动得少**，对饮食健康不重视，进而“**病从口入**”，导致身体出现问题，尤其是消化系统疾病的发生。例如：**急性胰腺炎、急性胆囊炎、肠梗阻、消化道穿孔、便秘加重致肠穿孔**等等以**腹痛**为主要症状的急腹症。

   春节饮食方面，通大附院胃肠外科提醒大家注意以下五点：

1、饮食清淡**少油腻**，搭配要均衡合理。过分“充足”的营养使**肥胖、高血压、糖尿病、高血脂、痛风**等人群在春节期间的发病率明显升高。

由于节假日活动量比上班时要少，因此最好注意调整一下自己的饮食，应该比平时更清淡些，多吃点容易消化的食物，适量吃些蔬菜、水果，可以减少脂肪的堆积。

2、新鲜水果不可少。节日饮食**杂乱**，更容易使人上火、便秘，根据个人情况适量吃些新鲜水果，既可以起到很好的清热、解毒、润肠功效，还能调节改善人体的代谢机能，预防各种疾病，增进身体健康。

3、主食不可忘。春节期间，人们大都习惯于多吃菜、少吃甚至不吃主食；对于健康而言，这是片面且不可取的。粮食是碳水化合物的主要来源，它参与脂肪、蛋白质的代谢过程，使其完全氧化，减少有毒物的生成，还为人体提供人体需要的膳食纤维。

4、宁可少吃一口，不让胃肠难受。聚餐家宴常常是很丰盛的，丰盛的菜肴往往使人食欲旺盛而“吃撑”了，造成胃肠的不适甚至消化系统疾病的发生，尤其是**急性胰腺****炎**、**急性胆囊炎**、**急性肠梗阻**等。最好的预防方法就是自我节制。

5、按时就餐莫贪玩，要饮食规律。新年的饮食要注意按时按点，不要打乱正常的饮食规律，使胃肠不适应而造成消化功能的紊乱。
